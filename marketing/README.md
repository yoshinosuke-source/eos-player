# EOS Player マーケティングキット

## 1. ポジショニング

| 項目 | 内容 |
|---|---|
| 一言で | 好きな曲で、英語が口から出てくるプレイヤー |
| カテゴリ | 歌で学ぶ英語学習ツール（ブラウザアプリ） |
| ターゲット | 洋楽で英語を学びたい日本語話者（社会人・学生・洋楽ファン・英語講師） |
| 競合の代替手段 | 音楽アプリ＋歌詞サイトの行き来 / 単語アプリ / 動画のリピート再生 |
| 差別化 | ①手持ちの曲が教材になる（Sync Studio）②1フレーズ固定ループ＋速度調整 ③行ごとの「定着／復習」記録 ④インストール不要・音源は端末内のみ |

### 価値の3本柱（訴求順）
1. **1行を、口が覚えるまで** — フレーズ固定ループ × 0.8倍速
2. **あなたの曲が、その場で教材に** — 歌詞を貼ってタップするだけの同期
3. **覚えたかが見える** — 「✓ 覚えた／↻ もう一回」で苦手な行が残る

## 2. コピー集

**メインコピー**
- 好きな曲で、英語が口から出てくる。

**サブコピー案**
- 聴き流しを、“身につく練習”に。
- 聴き取れない1行は、聴き取れるまでループ。
- 歌詞を貼って、タップするだけ。あなたの曲が英語教材に。
- インストール不要。音源はあなたの端末の外に出ません。

**CTA**
- 無料でブラウザから使う / 今日の1曲から、始めよう。

## 3. SNS投稿テンプレート

**X（告知）**
> 洋楽で英語、続かないのは「一瞬で流れていくから」。
> EOS Playerは聴き取れない1行だけを固定ループ＆0.8倍速。
> 歌詞を貼って曲に合わせてタップすれば、手持ちの曲がそのまま教材に。
> インストール不要👇
> #英語学習 #洋楽で英語

**X（機能紹介・スレッド向け）**
> 1/ 「Thirty-minute run」がなぜ単数？
> 歌詞の1行ごとに構文ポイントを確認できるのがEOS Playerのこだわり。
> 2/ 英語のみ表示でリスニング、日本語のみ表示で瞬間英作文。同じ曲で練習の形を変えられます。

**Instagram / TikTok（15秒動画の構成）**
1. 0–3秒: 「この1行、聴き取れる？」（英語のみ表示の画面）
2. 3–8秒: フレーズ固定ON → 0.8倍速でループ
3. 8–12秒: 1.0倍速で一緒に歌う
4. 12–15秒: 「✓ 覚えた」をタップ →「好きな曲で、英語が口から出てくる。」

## 4. 初期施策（低コスト順）
1. LP（`marketing/index.html`）を公開し、SNSプロフィールにリンク
2. 「今週の1行」シリーズ：毎週1曲の1フレーズを構文解説付きで投稿
3. 英語講師・英語系インフルエンサーにSync Studioでの教材化を紹介
4. note / ブログで「洋楽で英語を身につける練習法」記事 → LPへ誘導

## 5. 計測したい指標
- LP → アプリ遷移率（CTAクリック）
- アプリ側: MP3読み込み率 / Sync Studio完了率 / 「覚えた」タップ数
  ※現状アプリに計測は入っていないため、導入する場合はプライバシー方針（音源は端末外に出さない）と両立させること。

## 注意
- 音源・歌詞の著作権: 利用者自身が権利を持つ／私的利用の範囲で使う旨を明記する（LPのFAQに記載済み）。
- SNS素材でサンプル曲を使う場合は、オリジナル曲（例: “Call Me Yosshii!”）を使用する。
